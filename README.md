# اختبر معلوماتك — Ekhtabar Malomatak

منصة تعليمية عربية احترافية للاختبارات والتلخيصات، تدعم **الفصلين الدراسيين** بشكل كامل ومنفصل.

## نظرة عامة على المشروع
- **الاسم**: اختبر معلوماتك (ekhtabar_malomatak)
- **الهدف**: منصة اختبارات وتلخيصات للمرحلة الابتدائية (6 صفوف) مع فصل كامل بين الفصل الدراسي الأول والثاني.
- **أهم المميزات**:
  - 🆕 **نظام الفصلين الدراسيين**: اختيار الترم ثم الصف، وكل ترم له اختباراته وتلخيصاته الخاصة **بدون أي خلط**.
  - اختبارات تفاعلية بمؤقت، نقاط لكل سؤال، نسبة نجاح قابلة للتحكم.
  - تلخيصات (صور / يوتيوب / ملفات) مع فلترة بالترم والصف.
  - لوحة تحكم أدمن كاملة (إضافة/تعديل/حذف + استيراد JSON).
  - لوحة المتصدرين، المفضلة، الملف الشخصي، البحث.
  - 🆕 **أول 10 طلاب أوائل داخل القائمة المنسدلة** مع رقم الترتيب والنقاط.
  - 🆕 **منع إعادة الاختبار بعد الدرجة النهائية (100%)** — وإعادة حرة لو الدرجة أقل، مع احتساب **أعلى درجة** في النقاط.
  - 🆕 **درجات الطالب في صفحته الشخصية** (جدول درجات كامل + إحصائيات).
  - تصميم RTL عربي احترافي (Tailwind + تأثيرات حركية).

## 🆕 نظام الأوائل والنقاط والدرجات

### 1) قسم الأوائل في الصفحة الرئيسية
- قسم **🏆 قائمة الأوائل** يعرض منصة المراكز الثلاثة (الأول في المنتصف وأكبر) مع **شارة رقم الترتيب** والنقاط والميداليات.
- أسفله رابط **🏆 عرض أفضل 10 طلاب** لصفحة `/leaderboard`.
- ‏⚠️ تم **حذف زرار الأوائل المنسدل من أعلى الصفحة الرئيسية** (وجملة "أعلى ثلاث طلاب على المنصة") بناءً على طلب المستخدم — الاعتماد الأساسي أصبح على **القائمة المنسدلة (أول 10)** + قسم الأوائل في الصفحة + صفحة `/leaderboard`.

### 2) القائمة المنسدلة (الهيدر) — أول 10 طلاب
- داخل القائمة المنسدلة، خانة **الأوائل** قابلة للفتح (`#menu-leaders-section`) وتعرض **أول 10 طلاب** مرتّبين، وأمام كل واحد رقم ترتيبه ونقاطه.
- تُحمَّل البيانات بشكل **lazy** عند فتح القائمة فقط (`/api/leaderboard?limit=10`) لتقليل الطلبات.
- تعمل للطالب المسجَّل وللزائر على السواء، وبها حالة تحميل وحالة "لا يوجد".

### 3) قاعدة الدرجة النهائية (منع الإعادة)
- لو حصل الطالب على **الدرجة النهائية 100%** في اختبار → **لا يمكنه إعادته مرة أخرى**:
  - **على السيرفر**: `POST /api/quizzes/[id]/submit` يرجّع `403` مع `{ alreadyPerfect: true, resultId }`.
  - **على الواجهة**: `GET /api/quizzes/[id]` يرجّع `isPerfect` فيختفي زر البدء ويظهر بلوك مقفول، وزر "إعادة الاختبار" في صفحة النتيجة يختفي عند 100%.
- لو درجته **أقل من النهائية** → يعيد الاختبار **عدد مرات غير محدود بحُرّية**.
- **أعلى درجة فقط** هي التي تُحتسب في نقاط الطالب (`User.totalPoints` = مجموع أعلى `earnedPoints` لكل اختبار — بدون تكرار).

مثال متحقَّق منه فعليًا:
| المحاولة | النسبة | نقاط الطالب بعدها |
|---|---|---|
| 1 | 50% | 5 |
| 2 | 0% | 5 (لم تنقص ✅) |
| 3 | 100% | 10 |
| 4 | — | ❌ مرفوضة `403 alreadyPerfect` |

### 4) درجات الطالب في صفحته الشخصية (`/profile`)
- **5 بطاقات إحصائية**: عدد المحاولات، اختبارات حليتها، أعلى نسبة، نقاطي المحسوبة، درجات نهائية.
- **جدول "🎓 درجاتي"** (`#my-scores-table`): الاختبار / الدرجة (`score من totalQuestions`) / النقاط (`⭐ earnedPoints من totalPoints`) / النسبة / الحالة (🏆 نهائية · ✅ ناجح · ❌ راسب).
- الصفوف المحسوبة في النقاط مميّزة بلون ذهبي وعليها علامة **★ محسوبة في نقاطك**.
- سجل المحاولات أسفل الجدول يعرض النقاط وشارة **🏆 درجة نهائية**.

### 5) تصحيح الصياغة
- تم تعديل نص الزر في `/login` و `/register` إلى **«✨ إنشاء حساب»** (بدل «انشيء/أنشئ حساب»).

## 🆕 نظام الفصلين الدراسيين (Terms)

### تدفق التنقل
```
الرئيسية
  └── المرحلة الابتدائية  ->  /stage/primary            (صفحة اختيار الفصل الدراسي)
        ├── الفصل الدراسي الأول  ->  /stage/primary/term-1   (6 صفوف)
        │      └── الصف الأول .. السادس -> /grade/grade-N?term=term-1
        └── الفصل الدراسي الثاني ->  /stage/primary/term-2   (6 صفوف)
               └── الصف الأول .. السادس -> /grade/grade-N?term=term-2
```
- الترمان لهما **نفس الصور ونفس التأثيرات ونفس التصميم**، مع تمييز لوني لكل ترم.
- عند فتح أي صف: تظهر **اختبارات وتلخيصات ذلك الترم فقط**.
- يوجد مُبدّل ترم سريع (`#term-switcher` / `#grade-term-switcher`) للتنقل بين الترمين.

### التوافق مع البيانات القديمة
- حقل `term` افتراضيًا `term-2`.
- عند أول اتصال بقاعدة البيانات يعمل **ترحيل تلقائي غير مُدمِّر** (`migrateTerms()`): كل اختبار/تلخيص لا يحمل `term` يُعيَّن إلى `term-2` **بدون أي حذف للبيانات**.
- استعلامات `term-2` تستخدم `{ $in: ['term-2', null] }` لضمان ظهور أي بيانات قديمة.
- `normalizeTerm()` يقبل صيغًا متعددة (`term1`, `1`, `first`, `الأول`, ...) ويرجع `term-2` كافتراضي.

## الروابط (Entry URIs)

### صفحات عامة
| المسار | الوصف |
|---|---|
| `/` | الصفحة الرئيسية (اختيار المرحلة) |
| `/stage/primary` | اختيار الفصل الدراسي (الأول / الثاني) |
| `/stage/primary/term-1` | 6 صفوف — الفصل الدراسي الأول |
| `/stage/primary/term-2` | 6 صفوف — الفصل الدراسي الثاني |
| `/stage/preparatory` | المرحلة الإعدادية (قريبًا) |
| `/grade/[id]?term=term-1\|term-2` | اختبارات وتلخيصات صف معيّن في ترم معيّن |
| `/summaries?` | كل التلخيصات + فلترة بالترم والصف |
| `/quiz/[id]` | خوض الاختبار |
| `/result/[id]` | نتيجة الاختبار |
| `/leaderboard`, `/search`, `/profile`, `/favorites` | صفحات مساعدة |
| `/login`, `/register` | الدخول والتسجيل |

## بنية البيانات

### Quiz
```ts
{ title, stage, grade,
  term: 'term-1' | 'term-2',      // 🆕 افتراضي term-2، مفهرس
  duration, isActive, passingScore, coverImage,
  questions: [{ questionText, type: 'mcq'|'tf', optionA..optionD,
                correctAnswer, order, points, imageUrl }] }
```

### Summary
```ts
{ title, stage, grade,
  term: 'term-1' | 'term-2',      // 🆕 افتراضي term-2، مفهرس
  type: 'image' | 'youtube' | 'file', url, imageUrl, description }
```

### باقي الموديلات
- `User` — اسم + كلمة سر مشفّرة bcrypt + `isAdmin` + `totalPoints` (مفهرس تنازليًا للأوائل).
  - **قاعدة النقاط**: `totalPoints` = مجموع **أعلى `earnedPoints` لكل اختبار** (لا تُجمَع المحاولات المتكرّرة، ولا تنقص النقاط عند محاولة أسوأ).
- `QuizResult` — `userId`, `quizId`, `score`, `totalQuestions`, `earnedPoints`, `totalPoints`, `percentage`, `passed`, `answers` (Mixed).
  - يُستخدم للتحقق من الدرجة النهائية: `findOne({ userId, quizId, percentage: 100 })`.
- `Favorite`.

### خدمات التخزين
- **MongoDB / Mongoose** — قاعدة البيانات `ekhtabar_malomatak`.
  - محليًا: `mongodb-memory-server` مع مجلد بيانات دائم `./data/mongodb` (البيانات لا تُفقد عند إعادة التشغيل).
  - إنتاجيًا: `MONGODB_URI` (MongoDB Atlas).
- **Cloudinary** — رفع صور الأسئلة والأغلفة والتلخيصات (`/api/upload`).
- **JWT** — كوكي `auth_token` (httpOnly).

## دليل الاستخدام

### للطالب
1. من الرئيسية اختر **المرحلة الابتدائية**.
2. اختر **الفصل الدراسي الأول** أو **الفصل الدراسي الثاني**.
3. اختر صفك من الصفوف الستة.
4. تنقّل بين تبويب **الاختبارات** وتبويب **التلخيصات** — كل ما يظهر يخص الترم المختار فقط.
5. قبل بدء الاختبار تشوف لوحة **حالة محاولاتك** (أعلى نسبة + عدد المحاولات + رابط لأفضل نتيجة).
6. لو درجتك **أقل من 100%** → أعد الاختبار زي ما تحب وأعلى درجة هي اللي تُحتسب.
7. لو جبت **الدرجة النهائية (100%)** → الاختبار يُقفل ولا يمكن إعادته.
8. من `/profile` تشوف **جدول درجاتك الكامل** ونقاطك المحسوبة.
9. لمعرفة الأوائل: افتح **القائمة المنسدلة ← الأوائل** (أول 10 بالترتيب والنقاط)، أو انزل لقسم **قائمة الأوائل** في الصفحة الرئيسية، أو افتح `/leaderboard`.

### للأدمن
- الدخول: `/login` — الاسم: `أسماء نجيب` — كلمة السر: `Asoowr4477`
- **إضافة اختبار**: `/admin/quiz/new` → اختر 📅 الفصل الدراسي (الأول/الثاني) ثم الصف والأسئلة.
- **تعديل اختبار**: `/admin/quiz/[id]/edit` → يمكن نقل الاختبار من ترم لآخر.
- **إضافة تلخيص**: `/admin/summary/new` → اختر الفصل الدراسي والنوع.
- **استيراد JSON**: `/admin/import-json` — أضف `"term": "term-1"` أو `"term": "term-2"` لكل اختبار. لو لم تحدده يُسجَّل تلقائيًا في **الفصل الدراسي الثاني**.

- **المرحلة الإعدادية**: صفحة "قريبًا" كما هي (بانتظار المحتوى).

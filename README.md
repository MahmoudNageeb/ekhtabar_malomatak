## 📊 هيكل البيانات

### الجداول الأساسية:
- **User**: الاسم، كلمة السر (مشفرة)، المرحلة، الصف، إجمالي النقاط، صلاحيات
- **Quiz**: العنوان، المرحلة، الصف، المدة، حالة التفعيل
- **Question**: نص السؤال، النوع (mcq/tf)، الاختيارات (A,B,C,D)، الإجابة الصحيحة
- **QuizResult**: النتيجة، النسبة، JSON بكل الإجابات التفصيلية
- **Summary**: العنوان، النوع (image/youtube/file)، الرابط، صورة الغلاف
- **Favorite**: المفضلة (علاقة المستخدم بالاختبار)

## 🔌 نقاط الـ API

### المصادقة
- `POST /api/auth/register` - إنشاء حساب
- `POST /api/auth/login` - تسجيل دخول
- `POST /api/auth/logout` - تسجيل خروج
- `GET /api/auth/me` - بيانات المستخدم الحالي

### الاختبارات
- `GET /api/quizzes?grade=&stage=&search=` - قائمة الاختبارات
- `GET /api/quizzes/[id]` - تفاصيل اختبار (تخفي الإجابات للمستخدم العادي)
- `POST /api/quizzes` - إضافة اختبار (أدمن)
- `PUT /api/quizzes/[id]` - تعديل
- `DELETE /api/quizzes/[id]` - حذف
- `POST /api/quizzes/[id]/submit` - تسليم وتصحيح

### النتائج
- `GET /api/results` - كل النتائج (أدمن)
- `GET /api/results?search=name` - بحث بالاسم
- `GET /api/results/[id]` - تفاصيل نتيجة (المستخدم نفسه أو أدمن)

### الأوائل والملف الشخصي
- `GET /api/leaderboard` - أول 10 طلاب
- `GET /api/profile` - بيانات + سجل الاختبارات

### التلخيصات
- `GET /api/summaries?grade=&stage=` - قائمة
- `POST /api/summaries` - إضافة (أدمن)
- `PUT /api/summaries/[id]` / `DELETE` - تعديل/حذف

### المفضلة
- `GET /api/favorites` - مفضلة المستخدم
- `POST /api/favorites` - إضافة
- `DELETE /api/favorites?quizId=` - إزالة

### استيراد JSON
- `POST /api/admin/import-json` - استيراد اختبار واحد أو عدة (array)
